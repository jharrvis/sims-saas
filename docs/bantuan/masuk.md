# Masuk ke Aplikasi

> Dua cara login: kode OTP WhatsApp (utama) atau username + password (cadangan)

## Login dengan WhatsApp (utama)

1. Buka alamat aplikasi sekolah Anda (mis. `https://sma-anda.sims.id`), lalu klik **Masuk**.
2. Pastikan tab **WhatsApp OTP** aktif, masukkan **nomor WhatsApp** Anda (format: 62812xxxxxxx), klik **Kirim Kode**.
3. Anda menerima kode 6 digit via WhatsApp. Masukkan kode tersebut dalam **5 menit**.
4. Jika kode salah 5 kali, akun dikunci sementara — tunggu dan minta kode baru (ada jeda 60 detik antar permintaan).

> **Tips:** Pastikan nomor WhatsApp yang dipakai sama dengan yang terdaftar di sekolah. Jika belum terdaftar, hubungi admin sekolah.

## Login dengan username + password (cadangan)

Dipakai bila WhatsApp sedang bermasalah atau Anda lebih nyaman memakai password.

1. Di halaman login, pilih tab **Username + Password**.
2. Masukkan **username** dan **password** Anda, lalu klik **Masuk**.
3. Password dapat diatur sendiri di **Pengaturan → Keamanan Akun** (bagian **Password Akun**), atau direset oleh admin sekolah.

> Setelah 5 kali gagal, login password dikunci sementara selama 15 menit.

## Jika mengaktifkan 2FA

Jika Anda sudah **mengaktifkan verifikasi 2 langkah** (opsional), setelah kode WhatsApp atau password Anda akan diminta memasukkan kode dari aplikasi autentikator (Google Authenticator / Authy). Lihat topik **Keamanan Akun** di Pusat Bantuan.
