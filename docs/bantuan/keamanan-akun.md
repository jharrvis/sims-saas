# Keamanan Akun

> Verifikasi 2 langkah (2FA) dengan aplikasi autentikator

1. Buka halaman **2FA** (menu profil atau langsung ke alamat `/2fa/setup`).
2. Pindai kode QR dengan aplikasi autentikator di HP Anda (mis. Google Authenticator).
3. Masukkan kode 6 digit dari aplikasi untuk konfirmasi.
4. **Simpan 8 kode pemulihan** di tempat aman. Tiap kode hanya bisa dipakai sekali, untuk keadaan darurat jika HP hilang.

Catatan:

- **2FA wajib** untuk akun peran platform — Anda akan diminta menyalakannya sebelum bisa memakai aplikasi.
- Setiap sesi login baru meminta kode 2FA lagi, termasuk jika Anda masuk otomatis via "ingat saya".
- Jika akun Anda terdaftar di lebih dari satu sekolah, gunakan menu **Ganti Sekolah** untuk berpindah sekolah.
