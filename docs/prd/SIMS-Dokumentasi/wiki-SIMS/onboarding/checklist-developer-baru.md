# Checklist Developer Baru

> Buddy mendampingi selama 2 sprint pertama (SOP §13).

## Hari 1 — Konteks

- [ ] Baca `README.md` + Dok 13 (SOP Engineering) + [[Glosarium]]
- [ ] Install pre-commit hooks (`composer setup-hooks`)
- [ ] Minta akses: repo, staging, vault secret, Obsidian vault ini

## Hari 2 — Kode jalan

- [ ] Jalankan aplikasi lokal + seed demo hingga hijau
- [ ] Baca [[adr/0001-monolit-modular-laravel|ADR-0001]], [[adr/0002-shared-schema-multi-tenant|ADR-0002]], [[adr/0003-flat-pricing|ADR-0003]], [[adr/0004-identitas-global-membership|ADR-0004]], [[adr/0005-baseline-laravel-13|ADR-0005]]
- [ ] Buka 1 diagram di [[diagrams/_README|diagrams]] dan telusuri kodenya

## Hari 3 — Kontribusi pertama

- [ ] Ambil 1 *good first issue*, kerjakan berpasangan dengan buddy
- [ ] Buat PR pertama mengikuti template + checklist review (SOP §4.2)

## Minggu 1–2

- [ ] Pahami 1 modul end-to-end (kode + test + diagram)
- [ ] Jadi reviewer pendamping untuk 1 PR orang lain
- [ ] Tulis 1 catatan di wiki bila menemukan hal yang membingungkan (bayar ke depan)
